# GitHub解图 (astrbot_plugin_github_kantu)

在聊天里贴一个 GitHub 仓库链接，机器人**现场画一张**数据卡片给你。也可以发命令手动查。

**自动出图**（默认开启，不用发命令）：

```
https://github.com/koishijs/koishi
看看这个 https://github.com/koishijs/koishi/tree/main 怎么样
```

**手动查**（命令仍保留）：

```
/kantu koishijs/koishi
/kantu https://github.com/koishijs/koishi
/看图 koishijs/koishi
```

## 它是怎么工作的

| | 说明 |
| --- | --- |
| 数据来源 | 插件自己向 GitHub 接口拉取仓库数据 |
| 卡片绘制 | 用 Pillow 现场绘制，960×440，深色主题 |
| 卡片内容 | 星标 / 分叉 / 议题 / 语言 / 许可 / 最近活跃 / 头像 / 描述 |
| 触发 | 贴链接自动出图（只认完整链接，不认 `owner/repo` 裸写法），也能用 `/kantu` 手动查 |
| 出错 | 区分「仓库不存在 / 私有 / 被限流」，只回文字提示，不会把错误页当图发出去 |
| 重复请求 | 内存缓存，缓存期内复用上次画好的图 |

## 卡片内容

- 仓库名（`owner / repo`）与仓库描述（最多三行，超出自动省略）
- 星标数 / 分叉数 / 未关闭议题数
- 主要语言（带官方配色圆点）与开源许可
- 最近一次推送距今多久
- 仓库所有者头像（拿不到就用首字母占位）
- 已归档仓库会打上 `ARCHIVED` 标记

## 行为

- **贴链接就出图**。聊天里出现 `github.com/owner/repo` 链接会自动出卡片，不用发命令；不想自动出图可以在配置里关掉。
- **只认完整链接**。自动识别不认 `owner/repo` 裸写法，因为聊天里太容易误判（比如「昨天看了 a/b 两个方案」）。要查裸写法请用 `/kantu`。
- **机器人不喂自己**。机器人自己发出的消息不会触发，避免循环。
- **一条消息最多一张**。默认只给第一个链接出图，防止一口气贴十个仓库刷屏。
- **自动出图时静默失败**。仓库不存在、私有、被限流时，自动识别直接跳过；命令方式会回一句文字提示。
- **每个会话有冷却**。冷却期内自动识别静默跳过，不刷提示。
- **同一个仓库有缓存**。缓存期内复用上次画好的图，不重复请求。

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 自动识别聊天里的仓库链接 | 开 | 关闭后只能用 `/kantu` 命令查 |
| 单条消息最多出几张卡片 | 1 | 一条消息贴多个链接时的上限 |
| 出卡片时拦住大模型回复 | 关 | 开启后该消息不再交给大模型接话，避免「既出图又回一句」 |
| GitHub Token（可选） | 空 | 填了每小时额度从 60 次提到 5000 次，匿名访问很容易被限流 |
| 冷却时间（秒） | 3 | 同一会话内的命令间隔，0 表示不限制 |
| 卡片缓存时间（秒） | 1800 | 同一仓库复用上次成图的时长，0 表示不缓存 |
| 请求超时（秒） | 12 | 单次请求最长等待 |
| 代理地址 | 空 | 服务器连不上 GitHub 时填，例如 `http://127.0.0.1:7890` |
| 跳过证书校验 | 关 | 仅在证书链异常导致连不上时临时打开 |
| 卡片显示仓库头像 | 开 | 关掉可少一次网络请求 |
| 字体文件路径 | 空 | 卡片中文显示成方块时，手动指定一个中文字体 |

## 安装

把整个 `astrbot_plugin_github_kantu` 目录放进 AstrBot 的 `data/plugins/` 下，重载插件即可。

依赖：`aiohttp`、`Pillow` —— 两者都是 AstrBot 自带依赖，无需额外安装，也不需要浏览器或渲染服务。

## 已知限制

- **匿名访问 GitHub 接口有 60 次/小时限制**，人多或查得勤会被暂时拒绝。插件会提示「访问太频繁」，不会报错崩掉；填个 token 即可解决。
- 私有仓库画不出来，只会回一句提示。
- 卡片样式是固定的深色风格，暂不支持自定义配色。
